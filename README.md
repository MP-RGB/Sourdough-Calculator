# Wheat Sourdough (Android)

Liquid-levain and dough calculator. GitHub builds the Android app for you.

## Get the app
1. Open the **Actions** tab, then **Build Android app**, and wait for the green tick (about 5 minutes).
2. Open the **Releases** section (right-hand side of the repository page) and download `wheat-sourdough.apk`.
3. On your phone, open the downloaded file and allow "Install unknown apps" if asked.

## Update the app
Change files in the `www` folder (the calculator itself is `www/index.html`). Each change to `main` builds a new release.
